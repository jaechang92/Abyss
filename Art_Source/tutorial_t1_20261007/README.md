# 튜토리얼 안내 이미지 후보

2026-10-07, built-in imagegen 제작. `action-concepts.png` 1536×1024, 3열×2행: 이동 / 점프 / 대시 / 공격 / 폼 교체 / 스킬 선택. 불투명 장면형 시트, Unity 미연결.

어두운 작업장·낡은 철·푸른 회색·호박빛 행동 강조 방향을 검토한다. 배경과 테두리가 복잡하여 32/48px 픽토그램 완성품으로 통과시키지 않는다. 작은 월드 힌트용으로는 배경 없는 단순 실루엣을 개별 투명 PNG로 제작하고 축소 가독성을 확인해야 한다. 점프 그림의 틈은 개념 표현이며 실제 첫 방 지도에는 낙사 틈을 넣지 않는다.

키 문자·바인딩·한 줄 문구는 런타임 텍스트로 분리한다. 시트를 자동 분할하거나 게임 에셋으로 등록하지 않았다. [구간 지도·구현 인계](../../Docs/game-design/tutorial-t1/README.md).
