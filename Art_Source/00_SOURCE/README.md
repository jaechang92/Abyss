# 00_SOURCE — 소설 인용 대장

> 소설 『심연 지도』 전 3권(114장 · 486,735자)에서 **아트가 근거로 쓸 문장만** 뽑아 둔 곳.
> 요약이 아니라 **원문 그대로**다.

---

## 왜 이 폴더가 있나

두 가지다.

### ① 원격에는 소설이 없다

`Docs/`는 `.gitignore` 대상이다(사용자 결정 — 개인 학습 자료라 push 대상이 아니다).
그러므로 `10_BIBLE`이 *"소설 3권 21장 참조"*라고만 적으면 **원격에는 가리킬 대상이 없다.**

`Art_Source/`는 추적되므로, **이 폴더가 소설과 아트를 잇는 유일한 다리다.**

> 🔑 `_legacy/gen1-web-imagegen/GUIDELINE.md`가 정확히 이 병으로 죽었다 — 체크리스트가
> 가리키던 `_assembled_*.txt`가 다음 세대에서 삭제되면서 **항목들이 가리킬 대상을 잃었다.**

### ② 안 쟀으면 안 찍는다

소설 자신의 규칙이다(3권 14·19장). 아트 규약도 같은 것을 지킨다 —
**본문에 없는 것을 소설에서 온 것처럼 적지 않는다.**

gen1~3은 `dark fantasy underground ruins` 같은 장르 어휘를 세계 정체성에 넣었는데,
소설 실측으로는 **신·신성·여신·공허·고대·문명·회랑·왕좌가 전부 0회**다.
그 어휘는 소설에서 온 것이 아니었고, 파일만 봐서는 그것을 알 수 없었다.

---

## 인용 규칙

| | 규칙 | 왜 |
|---|---|---|
| 1 | **원문 그대로 옮긴다.** 줄이거나 다듬지 않는다 | 다듬는 순간 그것은 옮긴 것이 아니라 넣은 것이다 (3권 21장) |
| 2 | 출처는 `권/파일명:행` 으로 적는다 | `grep -n` 결과를 그대로 쓴다. 사람이 다시 찾을 수 있어야 한다 |
| 3 | 인용 아래 **아트가 무엇을 읽었는지**를 한 줄로 분리해 적는다 | 원문과 해석이 한 문단에 섞이면 다음 사람이 해석을 원문으로 읽는다 |
| 4 | 해석이 인용을 넘어서면 「지어낸 것」이라고 적는다 | 인용은 근거지 면죄부가 아니다 |
| 5 | 소설에 **없는 것**도 적는다 (0회 어휘) | 없다는 것도 잰 것이다 (3권 19장) |

## 다시 재는 법

```bash
cd Docs/novel
grep -rn "빛이 \|하늘이" 1권 2권 3권 --include="*.md"
grep -rhon "회색\|붉은\|검은" 1권 2권 3권 --include="*.md" | sed 's/^[0-9]*://' | sort | uniq -c | sort -rn
```

인용을 추가할 때는 **눈으로 고르지 말고 위처럼 훑은 뒤 고른다.** 눈으로 고르면 인상에 남은 것만 남는다.
