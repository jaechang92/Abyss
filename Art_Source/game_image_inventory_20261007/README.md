## 판정

**이미지 제작·파일 확인 / 코드 연결 미진행 / Unity·실제 화면 사용자 검증대기.** 이번 요청에서는 게임 코드·씬·기존 데이터의 icon 참조를 수정하지 않았다. 따라서 비어 있던 icon 필드는 실제 데이터에서 아직 비어 있다. 생성 파일이 Project에 나타나는 것과 게임이 사용하는 것은 별도 단계다.

UI용 이미지는 원본43종 alpha0 포함, 선택한 투명 이미지의 주요 윤곽(alpha>192)이 캔버스 가장자리에서 잘리지 않음, 프레임2종 중심 alpha0, 원본↔Unity 복사본 SHA256 일치, 새 meta GUID 중복 없음 확인. 테스트·빌드·Unity 실행은 하지 않았다. 제작 이미지의 세부 질감이 실제64~96px/32~40px 화면에서 어떻게 읽히는지는 아직 확인되지 않았다.

Stage2/3는 **배경 방향 후보**다. 레벨디자인에 맞춘 모든 룸·타일·콜라이더·패럴랙스 레이어 완성이 아니다. Stage3 원안은 큰 성채/아치가 미술 바이블의 평범한 공간과 어긋나 v2에서 작은 작업장·집으로 보완했다. 두 배경 모두 사용자의 미술 선택과 이후 실제 룸 배치 검증을 거쳐야 한다. 이번 배경 후보만으로 스테이지 완료 판정을 올리지 않았다.

## 실제 연결 인계

1. **아이콘 누락부터**: `tasks.json`의 evidence가 직접 대상 `.asset`이다. 스킬18/유물6/무기4 각 icon만 매핑한다. 기존12스킬/4폼/NPC/전투sprite·무기회전시트 보존. 이미지 GUID와 Sprite21300000 연결은 Unity 임포트 실제 subasset 확인 후 적용. ContentBuilder가 데이터를 재생성하면 새 참조가 사라지지 않도록 해당 생성 경로도 최소 범위로 확인한다.
2. **공통 표식**: GoldCounter/메타잔액/리롤/저장, RoomTypeDisplay 소비자의 이미지 표현, SynergyCounter. 런타임 숫자·상태·기존 라벨은 유지한다. 보스 경로=`CodexBossHud/codex/tab-boss-v1`, 이벤트 경로=`codex/undiscovered-v1` 재사용 제안. 물음표 아이콘 사용이 게임 잠금/보상 규약을 바꾸지 않는다.
3. **좁고 긴 화면**: 대화와 튜토리얼 프레임은 본문·NPC초상·키바인딩과 분리한다. 대화 프레임에는 초상 구분선/중간 리벳이 있으므로 일반9-slice로 모든 장식을 늘리지 않는다. 그림 비율에 맞춰 배치하거나 구분선과 끝장식을 고정한 별도 연결을 사용한다. 튜토리얼 목표의 완료/건너뛰기 조건은 그대로 유지한다.
4. **이전 제작20종 연결**: HUD/도감/보스 초상을 따로 최소 범위로 연결한다. 미발견 도감 항목에 실제 초상을 노출하지 않는다. BossPresenter와 CodexPanel은 같은 enemyId 매핑을 사용하도록 설계한다.
5. **환경**: 사용자가 후보 방향을 정한 뒤 실제 Stage2/3 대표방 크기·카메라·높낮이를 확정하고 배경/원경/전경/지면/플랫폼으로 분리 제작한다. 현재 배경 PNG에서 바닥을 충돌 타일로 자동 추출하지 않는다.

이미지에 실제 수치·설명·쿨다운·가격·보장되지 않은 효과를 굽지 않았다. 실제 glyph/text와 신규 이미지가 겹치지 않게 전환한다. 기존 구매·취소·교체·정산·EventSystem Submit/포커스 동작은 변경하지 않는다. 720p/1080p, 긴 이름/한국어/일본어, 낮은 잔액/비활성/도감 미발견 상태를 사용자 실기 확인 목록으로 남긴다.

## 여백과 원본 보존

`crop_hint_top_left`는 원본 pixel 파일을 자르지 않은 참고 영역이다. Unity rect의 좌하단 원점으로 변환할 때 `y = textureHeight - topY - height`를 사용한다. Single Sprite 준비본은 현재 전체 캔버스를 사용하므로 원본별 생성 여백/비율 차이를 연결 단계에서 조정해야 한다. 부드러운 반투명 외곽이 일부 후보에 남아 있어 밝은 배경에서도 확인해야 한다. 원안·수정본은 별도 이름으로 보존했고 이전 이미지/미커밋 변경을 덮어쓰지 않았다.

새 이미지 제작은 기능/콘텐츠 수·실기 판정을 바꾸지 않으므로 간트 완료율은 유지했다. Git 커밋·푸시 없음. Docs/memory 작업 기록은 로컬 전용이다.
