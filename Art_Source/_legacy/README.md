# Art_Source/_legacy — 폐기된 아트 프롬프트 세대

> 정리 2026-09-06. **읽기 전용이다.** 여기 있는 것을 고치지 않는다.
> 새 체계는 `Art_Source/` 아래 새 폴더에서 처음부터 다시 쓴다.

---

## 왜 전부 옮겼나

넉 달 동안 **생성 도구가 세 번 바뀌었다.** 그때마다 프롬프트 체계를 통째로 다시 썼고,
그때마다 앞 세대는 "폐기됨" 도장만 찍힌 채 같은 폴더에 남았다.
`GUIDELINE.md`·`README.md`는 첫 줄이 🔴 폐기 경고인데도 본문은 살아 있는 절차서처럼 읽혔다.

> **문서가 폐기 표시를 달고 원본 옆에 남아 있으면, 다음 사람은 그걸 절차로 읽는다.**
> 표시로 막는 대신 자리를 옮긴다.

두 번째 이유가 더 크다 — **세 세대 모두 출처가 게임 기획 문서였다.**
`gen3/prompts_env/01_world.txt` 헤더가 자기 출처를 적어 두었는데 넷 다 `Docs/game-design/`이다.
그러나 2026-08-19 대조(`Docs/game-design/13-novel-game-glossary.md`)에서
**기획 문서와 소설이 서로 다른 것을 주장한다**는 것이 확인됐고, 그때 SoT는 **소설**로 정해졌다.

아트만 아직 옛 SoT를 보고 있었다. 그래서 갱신이 아니라 재작성이다.

## 세대별

| 세대 | 도구 | 기간 | 범위 | 남긴 것 |
|---|---|---|---|---|
| `gen1-web-imagegen/` | 웹 image_gen (ChatGPT) | ~2026-08-26 | 폼 4종 정지 스프라이트 | 크로마키·측정 파이프라인 규격 |
| `gen2-novelai-v5/` | NovelAI Diffusion V5 | 2026-08-26~ | `dark_blade` 9상태 45프레임 | 태그 가중치 문법, 시트/낱장 부정 프롬프트 분리 |
| `gen3-pixellab/` | PixelLab (pixflux/bitforge) | 2026-09-03~ | 환경 8씬 94요청 | **앵커 + 강제 팔레트** 규약 |

### gen1 — 웹 image_gen

- `GUIDELINE.md` — 마젠타 크로마키 기준의 생성 지침. 실측값(팔레트 일치 89.7% 등)이 들어 있다.
- `README.md` — `prompts → raw → cut → frames → curated` 폴더 파이프라인.
- `base/dark_blade.png` — 폼 기준 이미지. **재생성 불가 원본**이라 지우지 않았다.

폐기 사유: 참조 이미지를 붙이는 수동 웹 UI 전제. 앵커가 가리키던 조립본 파일들이 gen2에서 삭제되며
체크리스트 항목이 **가리킬 대상을 잃었다.**

### gen2 — NovelAI Diffusion V5

- `prompts/01_character.txt` — 캐릭터 정체성을 **텍스트만으로** 붙드는 시도. V5에 Vibe Transfer가 없었다.
- `prompts/02_rules.txt` — 프레이밍·품질·알파·부정 프롬프트.
- `prompts/states/*.txt` — 9상태 포즈. `build.py`가 셋을 합쳐 `assembled/`에 낸다.

폐기 사유: 도구가 PixelLab으로 바뀌며 캐릭터 쪽은 착수 상태로 멈췄다.
**정체성을 문자열로만 붙드는 제약은 PixelLab의 `style_image`가 해소했다.**

### gen3 — PixelLab

- `prompts_env/01_world.txt` — 환경 세계 정체성. `[MOTIF]` 3종(fallen/carved/unclimbed)으로 씬 5개를 묶으려 했다.
- `prompts_env/02_params.txt` — 앵커 규약 + 종류별 파라미터.
- `prompts_env/scenes/` 8종, `parts/` 12종, `palettes/` hex 강제 팔레트.
- `env/anchor/` — 씬별 앵커 저장 위치(비어 있다. 실제 생성까지 가지 못했다).

폐기 사유: 위의 **출처 문제**. 도구 자체는 문제가 없었다.

## 새 체계로 가져갈 것 (버리지 않는다)

넉 달의 값은 실패한 프롬프트가 아니라 **실패의 형태를 안다는 것**이다.

| 가져갈 것 | 출처 | 왜 |
|---|---|---|
| **앵커 규약** — 씬/대상마다 사람이 고른 기준 한 장, 나머지는 거기서 파생 | gen3 `02_params.txt [ANCHOR]` | 한 장 다시 뽑는 값 < 스무 장 다시 뽑는 값 |
| **강제 팔레트** — 프롬프트는 부탁이고 `color_image`는 명령이다 | gen3 `[PALETTE]` | 배경↔캐릭터 색 충돌을 유일하게 실제로 막은 장치 |
| **조립 빌드** — 손으로 이어 붙이지 않는다. 한글 주석 유출 차단 | gen2·gen3 `build.py` | 손 조립은 매번 미세하게 갈린다 |
| **한 세션 안에서 끝낸다** — 날짜를 넘기면 같은 설정이어도 색온도가 갈린다 | gen2 §1 · gen3 §주의 | 실측된 것 |
| **먼저 하나를 끝까지 관통한다** — 전부 뽑기 전에 하나를 Unity 재생까지 | gen2 §5 · gen3 §5 | 45장·130장 뽑은 뒤 임포트 문제를 발견하면 전부 다시 |
| **낱장/시트 부정 프롬프트 분리** | gen2 `02_rules.txt` | 시트는 "여러 컷·테두리·여러 인물"을 오히려 원한다 |
| **실루엣으로 구분, 색으로 구분하지 않음** | gen1 `GUIDELINE.md §6` | 피격 플래시·폼 틴트가 색을 뭉갠다. 색약 대응이기도 하다 |
| **타일 재질 ≠ 배경 재질** | gen3 `00_WORKFLOW §4` | 160x96에서 풍경인 물건이 32px 타일에서는 타일을 다 차지한다 |
| **측정 도구** `Tools/ArtPipeline/` | gen1 | 생성기와 무관한 후처리라 도구가 바뀌어도 산다 |

## 새 체계에서 버릴 것

| 버릴 것 | 왜 |
|---|---|
| 출처를 `Docs/game-design/`에 두는 것 | SoT는 소설이다 |
| `dark fantasy underground ruins` 같은 장르 어휘 | 소설에 신·신성·여신·공허·고대가 **한 번도 안 나온다** |
| 도구 문법이 정체성 파일에 섞여 있는 것 | 도구가 세 번 바뀌었다. **정체성과 도구는 분리한다** |
| 씬 5개를 테마(유적·용암·왕궁·얼음·우주)로 가르는 것 | 소설의 층은 테마가 아니라 **남의 세계의 밑바닥**이다 |
