# 씬별 강제 팔레트 — make_palettes.py 가 이 파일을 읽어 PNG 로 굽는다.
# 구운 PNG 를 PixelLab 의 color_image 에 넣으면 그 색 밖으로 나갈 수 없다.
#
# 🔴 씬마다 파일을 나누지 않고 한 파일에 모은 이유 —
#    **나란히 놓고 비교하는 것이 이 파일의 용도**이기 때문이다.
#    지켜야 할 것은 각 팔레트가 예쁜가가 아니라 아래 4색과 안 부딪히는가다:
#
#      암흑검사   #EE773D  주황
#      공허궁수   #A36BF5  보라
#      고대방패병 #FFCC52  금
#      심연투척사 #7AC8BE  청록
#
#    이 색들은 이미 굳었고(develop 4c72c76 폼 아트 교체 완료) 전투 중
#    피격 플래시·폼 틴트로 순간 뭉개지므로, 배경이 같은 대역을 쓰면
#    플레이어가 자기 캐릭터를 잃는다. 배경이 양보한다.
#
# 🔑 판정 기준은 색상(hue)이 아니라 **명도와 채도**다.
#    스테이지 2 는 주황을 쓴다 — 다만 어둡고 탁한 주황이다.
#    같은 색상이어도 명도·채도가 갈리면 눈은 분리해 읽는다.
#
# 형식: [scene_id] 아래에 hex 를 줄마다 또는 공백으로. # 뒤는 주석.
# ══════════════════════════════════════════════════════════════
