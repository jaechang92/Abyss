# legacy/ — 안 쓰는 프롬프트

여기 있는 파일은 **build.py가 읽지 않는다.** 모델에 넣지도 않는다. 이력으로만 남긴다.

| 파일 | 무엇 | 왜 안 쓰나 |
|---|---|---|
| `void_archer_prompt.txt` | 공허 궁수 1회성 초안 | 블록 구조가 생기기 전에 손으로 통째로 쓴 것. 지금 `blocks/` + `forms/`가 대체한다 |
| `void_archer_v2_prompt.txt` | 위의 개정본 | 같음 |

## 왜 지우지 않았나

두 파일은 **블록 구조가 왜 필요했는지의 증거**다. 통짜 프롬프트에서는 스타일·정체성·프레이밍·
장비가 한 문단에 섞여 있어서, 리깅용으로 몸만 뽑거나 무기만 뽑을 방법이 없었다.
그게 `_anchor` → `_identity` → `reference`/`style`/`identity_figure` 로 계속 갈라 온 이유다.

## 왜 여기로 옮겼나 (2026-08-20)

예전에는 이 파일들이 `prompts/` 바닥에 조립본·블록·폼 파일과 **같은 높이로 섞여** 있었다.
파일이 서른 개 넘게 한 폴더에 있으니 "지금 모델에 넣을 게 어느 것인지"가 눈으로 안 잡혔고,
실제로 옛 프롬프트를 집어 쓰는 사고가 날 자리였다.

지금은 폴더가 역할을 말한다:

```
blocks/     공용 블록 (손으로 씀, 수정 금지)
forms/      폼별 블록 (손으로 씀, 수정 가능)
poses/      행 이미지용 포즈 문구 예시 (참고용, 조립 안 됨)
legacy/     여기 — 안 쓰는 것
assembled/  ← 모델에 넣는 것은 여기뿐. build.py가 만든다
```
