# poses/ — 행 이미지용 포즈 문구 예시

`build.py`가 **읽지 않는다.** 행 이미지(`<form>_sheet.txt`)를 뽑을 때 세 포즈를 직접 적어 넣는데,
그때 손으로 참고하는 문구다.

| 파일 | 상태 |
|---|---|
| `idle.txt` | 대기 |
| `walk.txt` | 이동 |
| `attack.txt` | 공격 |

⚠️ **`dark_blade` 기준으로 쓰여 있다.** 다른 폼에 그대로 붙이면 대검을 전제한 문장이 섞인다
(궁수에게 "검을 옆으로 늘어뜨린다"가 붙는 식). 폼에 맞게 고쳐 쓸 것.

조립 규칙은 `blocks/sheet_rules.txt`가 들고 있고, 그쪽은 자동으로 들어간다.
