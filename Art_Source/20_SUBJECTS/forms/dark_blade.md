# `dark_blade` — 암흑 검사

> UI 이름 **암흑 검사** · 시작 폼 · `hp x1.2 · 속도 x1.0 · 점프 2`
> 작성 2026-09-10 · **폼 주제 파일의 형식 기준이 되는 첫 장**

---

## ① 정체

> **넷은 다른 캐릭터가 아니라 같은 사람이 형태를 바꾼 것이다.**

**들은 것** (USP-2 · `_legacy/gen1 §6`): 같은 체격 · 같은 키 · **얼굴은 언제나 안 보임**.
그래서 폼을 가르는 것은 사람이 아니라 **그가 든 것과 걸친 것**이다.

암흑 검사는 넷 중 **기준선**이다 — 시작 폼이고 스탯이 전부 가운데다(hp 1.2 / 속도 1.0 / 점프 2).
나머지 셋은 이 폼에서 벗어난 방향으로 읽힌다.

## ② 소설 근거

⚠️ **`00_SOURCE/quotes-figure.md` 가 아직 없다.** 그래서 이 절은 「잰 것」을 못 단다 —
바이블 규칙 3(*인용을 못 달면 그건 잰 게 아니다*)에 따라 아래는 **들은 것**으로 표시한다.

**들은 것**: 색 어휘 전수에서 **검정 60회**로 압도적이다(`04-palette §1`).
「암흑」은 이 세계에서 특별한 속성이 아니라 **가장 흔한 것**이다.
→ 검사를 특별하게 그리지 않는다. 튀는 것은 무기이지 사람이 아니다.

🔴 **`quotes-figure.md` 를 쓰기 전에는 이 절이 비어 있다는 것을 잊지 말 것.**
지금 적힌 것은 색 통계에서 끌어온 간접 근거 하나뿐이다.

## ③ 시각 브리프

### 실루엣 — **대검을 몸에서 뗀다** (잰 것)

`10_BIBLE/08-silhouette §4` 의 2026-09-10 실측이 이 폼을 **실패**로 판정했다:

```
검사 vs 궁수 0.50   검사 vs 방패 0.52   검사 vs 투척 0.51    ← 어느 쪽과도 안 갈린다
채움 41.9%                                                  ← 투척사 40.6% 와 사실상 같다
```

원인은 크기가 아니라 배치였다. **대검이 몸에 붙어 사선으로 뻗어 있어 실루엣에 안 나온다.**
128px 로 키워도 같은 값이었다 — 겹쳐 있으면 커져도 안 보인다.

| | 배정 | 근거 |
|---|---|---|
| **실루엣 도형** | **세로 선** | `08-silhouette §4` |
| **그 도형을 만드는 것** | 대검 | 〃 |
| **🔴 배치** | **몸에서 떼어 수직으로 세운다.** 날이 어깨 위로 나가거나 발밑으로 내려가 **몸 밖에 선이 그어져야** 한다 | 궁수가 유일하게 읽힌 이유가 활이 몸 밖에 있어서였다 |
| **채움 면적** | **41.9% 에서 내린다** — 투척사와 겹친다. 목표는 궁수(36%)와 방패(71%) 사이의 **35~45% 하단** | 아래 「밀도 = 무게」 |
| **밑단** | 🔴 **넝마를 줄인다.** 넷이 공통으로 가진 로브 밑단이 IoU 0.5 의 정체다 | 〃 |
| **얼굴** | 안 보인다 | ① |
| **램프** | 밝은 면 `99A6AC`~`D2D9DB` · 어두운 면은 환경과 겹쳐도 된다 | `08-silhouette §2` |
| **윤곽선** | selective. 검정으로 두르지 않는다(최암 `#0B0E11`) | `08-silhouette §3` |

### 🔑 밀도 = 무게 (잰 것 — 이번에 발견했다)

실루엣 채움 면적이 **이미 스탯과 대응하고 있었다**:

```
방패병  hp x1.5  속도 x0.85  채움 71.0%      무겁다
검사    hp x1.2  속도 x1.00  채움 41.9%
투척사  hp x0.9  속도 x1.15  채움 40.6%   ← 검사와 채움까지 같다
궁수    hp x0.9  속도 x1.15  채움 36.2%      가볍다
```

방패병의 71% 는 고칠 결함이 아니라 **살릴 신호**다(그쪽은 「사람 윤곽이 남는가」가 따로 문제다).
반대로 **검사와 투척사는 스탯이 다른데 채움이 같다** — 여기가 이 폼의 진짜 결손이다.

📌 **이것을 규약으로 세운다: 실루엣 밀도가 무게를 말한다.**
넷을 다시 그릴 때 채움 면적이 스탯 순서(방패 > 검사 > 투척 > 궁수)를 따르는지 잰다.

### 안 그리는 것

- 🔴 **강조색을 쓰지 않는다.** 색은 시너지 축이 가져갔다(`04-palette §1`).
  옛 배정 「불꽃 주황」은 폐기됐다 — 검사가 불꽃 축 전용이 아니다
- 광원·발광 없음 (`03-light` L1)
- 초록 없음 (P5)

## ④ 뽑을 것 — 상태 9종

`PlayerAnimationIds` 가 SoT다. **코드가 이미 정한 목록이고 아트가 바꾸지 않는다.**

```
Idle   Run   Jump   Fall   Dash   AttackLight   AttackHeavy   Hit   Dead
```

⚠️ 상태별 프레임 수는 **여기서 안 정한다.** 간트에 「프레임 6~8장」 방침이 확정으로 적혀
있지만 **손그림 시절 방침이라 다시 확인해야 한다**(`08-silhouette §6`).

🔴 **시트로 여러 자세를 한 번에 뽑을 때 gen1 에서 두 번 터졌다** (`08-silhouette §7`):
프레임 사이 간격이 좁아 **칼끝이 옆 프레임을 침범**했고(분리가 3개 대신 1개),
자세별 배율이 제각각이라 **키가 12.7% 흔들려** 애니메이션에서 위아래로 떨었다.
📌 **대검을 몸 밖으로 빼면 이 위험이 커진다.** 배치를 바꾸는 결정과 시트 규격이 맞물린다.
