# `void_thrower` — 심연 투척사

> UI 이름 **심연 투척사** · `hp x0.9 · 속도 x1.15 · 점프 2`
> 작성 2026-09-10 · 형식은 `dark_blade.md` 기준
> 🔴 **넷 중 가장 어려운 폼이다** — 아래 ①

---

## ① 정체

**들은 것** (USP-2): 넷은 **같은 사람이 형태를 바꾼 것**이다. 같은 체격 · 같은 키 · 얼굴 안 보임.

🔴 **이 폼은 두 방향에서 동시에 눌려 있다:**

```
스탯    hp 0.9 · 속도 1.15  →  궁수와 완전히 같다 (점프만 2 vs 3)
축      abyss (심연)        →  궁수와 같은 축이다
실측    검사와 IoU 0.51 · 채움 40.6% (검사 41.9%) — 검사와도 거의 같다
        방패와 IoU 0.58 — 여섯 쌍 중 가장 안 갈린다
```

**즉 궁수와는 스탯·축이 같고, 검사와는 실루엣이 같고, 방패와는 가장 안 갈린다.**
넷 중 유일하게 **자기 자리가 없는 폼**이고, 그래서 옛 시도가 여기서 먼저 깨졌다 —
*"투척사는 설정상 심연 축이지만 궁수와 같은 보라를 쓰면 구분이 안 되어 청록으로 갈랐다"*
(`_legacy/gen1 §6`). **색으로 갈랐다는 것 자체가 형태로 못 갈랐다는 자백이다.**

## ② 소설 근거

⚠️ **`00_SOURCE/quotes-figure.md` 가 아직 없다.** 아래는 **들은 것**이다.

**들은 것**: 색 어휘 전수에서 **보라·청록 0회**다(`04-palette §1`). 옛 배정의 청록 `#7AC8BE`는
이 세계에 없는 색이었고, 그것으로 궁수와 갈랐다는 것은 **세계 밖 수단을 쓴 것**이다.
→ 이 폼은 **형태로만** 갈려야 한다. 물러설 자리가 없다.

## ③ 시각 브리프

### 실루엣 — **넷 중 유일하게 「무엇을 만들지」부터 다시 정해야 한다**

`10_BIBLE/08-silhouette §4` 실측:

```
검사 vs 투척 0.51   채움 40.6% vs 41.9%   ← 형태도 밀도도 검사와 같다
방패 vs 투척 0.58                          ← 여섯 쌍 중 가장 안 갈린다
```

옛 자산에서 이 폼의 유일한 특징은 **위로 든 팔** 하나였다. 그것은 자세이지 형태가 아니라
다른 상태(Run·Jump·Hit)에서 사라진다 — **9개 상태를 관통하는 실루엣이 없다.**

| | 배정 | 근거 |
|---|---|---|
| **실루엣 도형** | **삼각** | `08-silhouette §4` |
| **그 도형을 만드는 것** | 퍼지는 망토 | 〃 |
| **🔴 배치** | **망토 밑단을 넓게 벌려 삼각을 실루엣 바깥에 만든다.** 위→아래로 벌어지는 윤곽이 서야 한다 | 자세가 아니라 형태여야 9개 상태를 관통한다 |
| **🔴 방패와 충돌** | 방패도 「넓은 덩어리」다. **넓히면 0.58 이 더 오른다** — 삼각은 **아래만 넓고 위는 좁아야** 사각과 갈린다 | 실측 |
| **채움 면적** | **35~40%.** 검사(목표 35~45% 하단)보다 **아래**여야 한다. 망토는 넓히되 **속이 비어 보이게** | 밀도 = 무게 |
| **궁수와의 구분** | 궁수는 **곡선이 몸 옆**, 투척사는 **삼각이 몸 아래**. 방향이 달라야 한다 | ① |
| 밑단 | 🔴 **여기만 예외다** — 넷 중 이 폼만 밑단을 **넓힌다.** 나머지 셋은 줄인다 | 삼각의 근원 |
| 램프 · 윤곽선 | `dark_blade.md ③` 과 같다 | `08-silhouette §2,3` |

📌 **밑단 규약이 폼마다 갈린다는 것이 이 파일의 발견이다.** `08-silhouette §4` 는
*"넷 다 아래가 같은 로브 밑단"*을 문제로 지적하며 **줄이라**고 적었는데, 투척사만은
그 밑단이 **유일한 형태 후보**다. → 셋은 줄이고 하나는 넓힌다. 그래야 넷이 갈린다.

### 안 그리는 것

- 🔴 **강조색 없음.** 옛 배정 청록 `#7AC8BE` 는 **세계에 없는 색**이었고 폐기됐다(② 참조)
- 광원·발광 없음 (L1) · 초록 없음 (P5)

## ④ 뽑을 것 — 상태 9종

```
Idle   Run   Jump   Fall   Dash   AttackLight   AttackHeavy   Hit   Dead
```

🔴 **이 폼은 9개 상태 전부에서 삼각이 유지되는지 봐야 한다.** 망토는 자세를 따라 움직이므로
Run·Dash 에서 뒤로 날리면 삼각이 사라진다. **가만히 선 Idle 에서만 삼각인 것은 실패다** —
옛 자산의 「위로 든 팔」이 정확히 그 실패였다.
