# 20_SUBJECTS — 대상 카탈로그

> **무엇을 그리는가.** 바이블이 *어떻게* 그리는지를 정하고, 여기는 *무엇을* 그리는지를 센다.
> 한글 + 데이터 키.

## 명명 규약 🔴

**파일 이름이 곧 게임 데이터 키다.** 새 이름을 만들지 말고 에셋에서 복사한다 — 오타는 조용히 안 붙는다.

| 폴더 | 키의 출처 | 예 |
|---|---|---|
| `scenes/` | `StageData` · 씬 파일명 | `stage1_rift_entrance` · `lobby` · `title` |
| `forms/` | `FormData.formId` | `dark_blade` · `void_archer` · `ancient_shield` · `void_thrower` |
| `enemies/` | 적 데이터 ID | |
| `props/` | 방 타입 · 상호작용 오브젝트 | |

## 대상 하나 = 파일 하나

각 파일이 담는 것:

```
① 정체        이것은 무엇인가 (한 문장)
② 소설 근거   00_SOURCE 인용, 또는 「소설에 없음」이라고 적는다
③ 시각 브리프 바이블의 어느 항목이 어떻게 적용되는가
④ 변형        뽑아야 할 장수와 그 차이
⑤ 미결        아직 안 정한 것
```

## 씬은 「무엇이 없는가」로 적는다

소설의 층은 전부 결여로 갈린다 — 하늘이 없다 / 소리가 없다 / 볼 것이 없다 / 말이 없다 / 이름이 없다
(→ `00_SOURCE/quotes-layer.md §1`).

그러므로 씬 파일에는 **테마(불·얼음·왕좌)가 아니라 결여 한 줄**을 먼저 적는다.
테마는 그다음에 온다.

> 💡 근거: `2권/09-놓는 것.md` — 하란이 안 간 층들의 지도 팔백 장.
> *"얼음이 있었다. 불이 있었다. **층 이름은 적혀 있지 않았다.**"*
> **게임의 스테이지 이름은 게임이 붙인 것이므로, 시각 브리프를 이름에서 뽑지 않는다.**
