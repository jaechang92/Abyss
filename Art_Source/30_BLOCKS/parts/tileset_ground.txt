# 지면 타일셋
#
# 🔑 심리스 타일셋을 도구가 만들어 준다는 것이 이 파이프라인의 큰 이득이다.
#    이어 붙는 격자로 나오므로 Unity Tilemap 에 그대로 들어간다 —
#    심리스를 손으로 맞출 필요가 없다.
#
# 이 파일이 말하는 것은 둘이다: [INNER](밟는 땅의 속) / [TRANSITION](윗면, 서는 자리).
#
# ⚠️ [OUTER](땅이 아닌 것)도 아래에 적혀 있지만 **생성에 안 실린다** —
#    2026-09-07 에 확인했다. 땅 밖은 그려지지 않고 비어서 나온다.
#    지우지 않는 이유는 그것이 여전히 **이 씬의 사실**이기 때문이다(땅 밖에 무엇이 있는가).
#    그 사실은 배경 레이어가 말한다. 도구 층이 메타로 넘겨 받는다.
#
# 🔴 재질은 씬의 [MATERIAL] 이 아니라 [GROUND-MATERIAL] 을 쓴다. (10_BIBLE/06 C7)
#    [MATERIAL] 은 배경(160x96)용이라 **물건**이 섞여 있다. 배경에서는 풍경이지만
#    32px 타일 안에서는 그 물건 하나가 타일을 다 차지하고, 바닥을 깔 때마다 반복된다.
#    **심리스가 눈에 보이는 순간 타일은 죽는다.**
#    build.py 가 [USE-SCENE] 순서로 먼저 있는 블록을 쓴다(없으면 MATERIAL 폴백).
#
# 🔴 outer 는 씬이 덮을 수 있다 — 씬 파일에 [TILE-OUTER] 가 있으면 그쪽이 이긴다.
#    stage5(고인 데)는 바닥 밖이 허공이 아니라 물이다.
#
# ⚠️ transition 이 이 게임에서 가장 중요한 한 줄이다 — **플레이어가 서는 면**이다.
#    Unity Tilemap 콜라이더는 격자 칸 경계라, 윗면이 울퉁불퉁하게 그려지면
#    보이는 바닥과 밟히는 높이가 어긋나 캐릭터가 떠 있거나 파묻혀 보인다.
#    벽은 broken edge 가 맞지만 **지면은 평평한 한 줄**을 요구한다.
#    그래도 윗면이 울퉁불퉁하게 나오면 **도구 층에서 구조 엄격도를 올린다**
#    (어느 칸인지는 40_TOOLS 가 안다 — 여기서 칸 이름을 부르지 않는다).
#
# 💡 소설이 이 파트를 지지한다 — "돌이 평평했고"(3권 13장) · "땅이 있었다. 평평했다"(3권 1장).
#    평평함은 엔진 사정이면서 동시에 이 세계의 사실이다. (10_BIBLE/06 C5)
# ══════════════════════════════════════════════════════════════

[KIND] tileset
[PARAMS] PARAMS-TILESET
[USE-SCENE] GROUND-MATERIAL, MATERIAL
[COUNT] 1

[INNER]
# 캐릭터 뒤로 화면에서 가장 넓게 깔리는 면이다. 조용할수록 캐릭터가 산다.
# "nothing lying on it" 은 금지어가 아니라 서술이다 — 이 면 위에는 물건이 없다.
solid packed ground, one even repeating material, nothing lying on it

[TRANSITION]
# 밟는 면. "평평함"과 "여기서 땅이 끝난다"가 동시에 읽혀야 한다.
#
# 🔴 2026-09-09 — `slightly lighter than the ground below` 를 뺐다. **잰 것:**
#    그 한 마디가 상판을 **따뜻한 베이지**로 만들었고(이 씬에서 금지된 색),
#    집행 후에도 램프 **위 3단을 7.9%** 쓰게 했다 — 캐릭터에게 남겨 둔 대역이다.
#    모델이 「밝게」를 **명도가 아니라 색온도로** 읽었다.
#    ⚠️ W4(부정문을 긍정문으로)로 막을 수 있는 종류가 아니다. 어휘가 아니라 기본값이다.
#
# 🔑 그래도 **서는 자리는 선으로 보여야 한다**(원래 의도는 가독성이었다).
#    그래서 명도 대신 **결**로 가른다 — 발에 닳아 촘촘해진 면 vs 거친 속.
#    명도를 안 건드리므로 L3(좁은 대비)도 위 3단도 안 침범한다.
the flat level top surface, one straight walkable line,
rubbed smooth by feet, a finer tighter grain than the coarse body below,
the same dark stone throughout

[OUTER]
dark empty air
