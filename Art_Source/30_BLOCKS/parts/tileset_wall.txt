# 벽면 타일셋
#
# 지면과 별개로 뽑는다. 같은 재질이어도 **벽은 세로로 이어지고 지면은 가로로 이어진다** —
# 한 타일셋으로 둘 다 하면 한쪽이 반드시 어색해진다.
#
# 🔴 gen3 의 미해결을 여기서 닫는다 — 그때는 벽이 [MATERIAL](배경 재질)을 그대로 썼고
#    00_WORKFLOW.md 가 "같은 문제가 남아 있다"고 적어 두었다.
#    이제 [WALL-MATERIAL] 을 먼저 보고, 없으면 GROUND-MATERIAL, 그다음 MATERIAL 로 떨어진다.
#    지면 어휘(floor slabs)를 벽에 그대로 쓸 수 없으므로 씬이 벽 재질을 따로 적는다.
#
# ⚠️ 벽은 지면보다 한 단계 더 어둡고 조용해야 한다. 화면에서 차지하는 면적이 가장 넓어서,
#    여기가 시끄러우면 다른 무엇을 조용하게 만들어도 화면이 안 정리된다.
#
# 💡 윗면 층을 지면보다 두껍게 준다 — 벽은 두께가 보여야 벽으로 읽힌다.
#
# 🔴 **지면 다음에 뽑는다** ([FOLLOWS]). 같은 재질이어도 따로 뽑으면 둘이 갈리는데,
#    먼저 만든 타일셋을 기준으로 삼으면 이어 붙게 나온다.
#    이미지 쪽에서 앵커가 하는 일을 타일셋에서는 이 줄이 한다.
#    ⚠️ 그래서 **순서가 규약이다.** 벽을 먼저 뽑으면 벽이 기준이 되고, 지면이 벽을 따라온다.
#
# 📌 벽은 [MOTIF] carved 가 가장 잘 붙는 자리다 — 벽에 손으로 새긴 이름(3권 21장).
#    다만 타일에 글자를 구우면 반복되므로, 글자는 prop_decor/prop_interactive 로 얹는다.
# ══════════════════════════════════════════════════════════════

# 🔴 2026-09-09 — **[FOLLOWS] 를 뺐다가 되돌렸다.** 네 라운드의 실측이다.
#
#     확정 지면(2차)  평균 단 2.87   위3단 0.00%
#
#     벽 1차 (체인)   4.23  위3단 11.69%  교집합 23.2%   계조 살아 있음
#     벽 2차 (체인)   3.66  위3단  0.00%  교집합 79.7%   구조 어휘 추가
#     벽 3차 (체인)   3.27  위3단  0.00%  교집합 76.7%   deep dark 추가   ← 채택
#     벽 4차 (체인X)  1.02  위3단  0.00%  교집합 31.0%   🔴 한 색이 97.7% — 납작해졌다
#
# 🔑 **체인은 밝기 앵커가 아니라 재질 앵커였다.** 빼니까 규약대로 어두워지긴 했는데
#    (1.02 < 2.87) **그림이 사라졌다** — 한 색이 97.7%면 벽이 아니라 검은 면이다.
#    「ΔE 0 도 합격이 아니다」와 같은 실패다(10_BIBLE/04 §5). 어두움은 얻고 재질을 잃었다.
#
# ⚠️ 그래서 **3차를 채택했고, 규약 한 줄은 미달로 남는다** —
#    이 파일 머리말의 "벽은 지면보다 한 단계 더 어둡고"가 안 지켜졌다(벽 3.27 > 지면 2.87).
#    지키려면 체인을 빼야 하고, 그러면 재질이 죽는다. **둘 다 가지는 길을 아직 못 찾았다.**
#    다음에 시도할 것: transition_size 0.4 → 0.15 (윗면 밝은 띠가 평균을 올리고 있다)
#                     또는 지면을 한 단 밝게 (지금 지면이 2.87 로 매우 어둡다)
# ══════════════════════════════════════════════════════════════

# 🔑 고친 방식 — **비교가 아니라 관측으로 적는다**(W2). "지면보다 어둡게"라고 쓰면
#    모델이 지면을 보고 있어야 성립하는데, 그건 [FOLLOWS] 가 있을 때만이고 불안정하다.
#    대신 **벽에서만 관측되는 것**을 적는다: 세로로 쌓인 켜, 깊이 팬 줄눈, 방에서 가장 어두운 면.
#    지면은 가로 슬래브·밟혀 닳은 상판이라 관측 자체가 겹치지 않는다.
