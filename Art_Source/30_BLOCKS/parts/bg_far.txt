# 원경 레이어 — 규모를 담당한다
#
# 여기에 큰 것이 서면 플레이어는 자기가 얼마나 작은 곳에 있는지 안다.
#
# 🔑 실루엣만 그린다. 원경에 재질이 보이면 중경과 층이 안 갈린다 —
#    패럴랙스는 속도로 층을 나누지만 **눈은 선명도로** 층을 나눈다.
#
# 🔴 그리고 이 파트에는 그보다 강한 이유가 하나 더 있다 — 10_BIBLE/06 C4:
#    **원경 물체는 무엇인지 읽히면 안 된다.**
#      "멀리 무엇인가 서 있었다. 여럿이었다.
#       사람인지 나무인지 이 거리에서는 알 수 없었다." (3권 1장)
#    하란이 못 알아본 거리를 플레이어가 알아보면 그 씬은 소설의 그 자리가 아니다.
#
# ⚠️ 그래서 "원경이 심심하다"는 이유로 디테일을 더하면 그림이 좋아지는 게 아니라
#    **틀린다.** 이 조항은 반드시 다시 흔들린다. 그때 이 줄을 근거로 거절한다.
# ══════════════════════════════════════════════════════════════

# 🔴 2026-09-08 — [LIGHT] 를 뺐다. 이 파트에 그 블록이 갈 자리가 없다.
#
#    [LIGHT] 는 씬의 빛 거동을 **표면이 어떻게 읽히는가**로 적는 블록이다
#    (10_BIBLE/03 §2 — 한 뼘을 못 간다 / 퍼진다 / 선에서 끊긴다 / 늘 같다).
#    그런데 이 파트는 위 주석대로 **읽히는 표면이 없는 것이 조건**이다.
#    읽히다 마는 이야기를 읽히면 안 되는 층에 싣고 있었다.
#
#    그리고 패럴랙스 쪽 이유가 더 크다 — 끊기는 선이 sky·far·mid 에 다 있으면
#    **세 개가 서로 다른 속도로 미끄러진다.** 하나여야 선이다.
#    선은 중경(bg_mid)에만 둔다. 씬 카탈로그 ⑥ 의 미결
#    「빛이 끊기는 선을 배경 레이어 어디에 두나」의 답이 이것이다.
#
