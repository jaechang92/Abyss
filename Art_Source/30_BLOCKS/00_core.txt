[CORE]
# 🔴 gen3 는 여기가 `dark fantasy underground ruins` 였다.
#    `ruins`(폐허)는 소설 전권 **0회**이고, 실제로 이 세계의 층은 대부분 폐허가 아니다 —
#    8층은 "집이 많았다. 사람이 많았다"(3권 13장)이고 계단의 마을에는 밭이 있다.
#    부서진 것을 그리는 것과 비워진 것을 그리는 것은 완전히 다른 그림이다. (10_BIBLE/01 W2)
dark underground stone

[TONE]
# 00-concept §5 + 소설 문체 규약. 대단한 존재가 아니라 사람이 있던 자리다.
#
# 💡 처음에는 `not ruined` 였는데 build.py 의 [FORBIDDEN] 검사가 `ruined` 를 잡아
#    빌드가 멈췄다 — **검사가 그것을 쓴 사람을 먼저 잡은 셈이다.**
#    고쳐 놓고 보니 검사가 옳았다: 부정 서술("~가 아니다")은 이미지 모델에 약하다.
#    모델은 "ruined 를 빼라"가 아니라 "ruined"를 읽는다.
#    긍정으로 말한다 — 폐허가 아니라는 것은 **아직 서 있다**는 것이다. (10_BIBLE/01 W2)
quiet, plain, worn, still standing, nothing heroic

[MOTIF]
# 🔴 층을 하나의 세계로 묶는 것. 파트마다 이 중 **하나만** 골라 쓴다(전부 넣으면 희석된다).
#
#   carved     벽에 손으로 새긴 이름. 그리고 그 글자가 줄어든다.
#              3권 21장 — 같은 이름을 열넷 썼는데 세 글자 다섯 → 두 글자 셋 →
#              한 글자 넷 → 마지막 둘은 글자가 아니라 획이었다.
#   unclimbed  아무도 못 올라갔다. 위를 향하다 만 것만 남았다. (2권 삼천 단 계단)
#   left       사람이 하나씩 나갔고 살림은 그대로다.
#              3권 18장 — "살림이 그대로고 먼지가 고르다. 급했으면 자국이 어지럽다"
#   fallen     위에서 내려온 것. 이 세계의 방향은 언제나 아래다.
#
# ⚠️ gen3 의 fallen 은 `rubble fallen from above`(잔해)였다. 폐허 어휘라 바꿨다.
carved = names scratched into the stone by hand, the letters getting shorter
unclimbed = a stairway that stops partway up
left = belongings still in place, dust lying evenly
fallen = things that came down from somewhere above
