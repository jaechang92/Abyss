[MOTIF]
# 🔴 층을 하나의 세계로 묶는 것. 파트마다 이 중 **하나만** 골라 쓴다(전부 넣으면 희석된다).

#   carved     벽에 손으로 새긴 이름. 그리고 그 글자가 줄어든다.

#   left       사람이 하나씩 나갔고 살림은 그대로다.

#   fallen     위에서 내려온 것. 이 세계의 방향은 언제나 아래다.
#
# ⚠️ gen3 의 fallen 은 `rubble fallen from above`(잔해)였다. 폐허 어휘라 바꿨다.

# 🔴 2026-09-08 `light` 추가. 이 검사가 처음으로 **놓친 것**을 보고 넣는다.
#
#    stage1 앵커 후보 4장이 전부 L1(광원)로 탈락했다. 씬 [LIGHT] 문구가
#    `light stops at one hard straight edge` 였고 광원 금지는 **한글 주석에만** 있었다.
#    조립기는 주석을 걷어낸다 — 옳은 동작이다. 모델에게 남은 것은
#    "빛이 있고 그것이 단단한 직선에서 멈춘다"뿐이고, 멈추는 것이 보이려면
#    웅덩이가, 웅덩이가 있으려면 광원이 있어야 한다.
#    🔑 **문구가 광원을 말하지 않으면서 요구했다.** 목록에 `sunbeam`·`glow` 는 있었지만
#       `light` 는 없었으므로 검사는 통과시켰다. 낱말은 안 걸렸고 그림은 걸렸다.
#
#    📌 여기서 배운 것: **금지가 주석에 있으면 없는 것과 같다.**
#       [TONE] 의 `not ruined` 를 이 검사가 잡았던 것과 같은 계열인데 방향이 반대다 —
#       그때는 검사가 쓴 사람을 먼저 잡았고, 이번에는 검사에 없는 낱말이 새 나갔다.

#    ⚠️ 그래서 앞으로 빛 거동(10_BIBLE/03 §2)은 **빛이 아니라 보이는 것**으로 적는다.
