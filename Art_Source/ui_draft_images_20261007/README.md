## 제작·검토

- 코드를 통한 선 그리기보다 이미지 에셋 중심이라는 사용자 방향을 반영. 기존 프로시저 스킨·게임 코드 수정 없음.
- RGBA/중앙alpha0/투명 외곽 확인. 크기·가시영역은 manifest.json에 기록. 원본에 생성 모델의 비균일 픽셀/미세 가장자리 색 흔적이 남을 수 있음.
- 기본 프레임과 선택 프레임은 생성 여백이 다름. 같은 PNG 전체크기로 바로 겹치면 어긋나므로 실제 visible_bbox를 기준으로 테두리 위치/안쪽 패딩을 별도 정렬해야 함.
- 선택본은 시안의 ivory보다 따뜻한 금색이 강한 후보. 미술 채택/실제 어두운면에서의 대비 판단 필요.
- 상세 PNG 전체는 넓은 캔버스 여백을 포함하므로 가시 프레임 영역의 실측 비율을 기준으로 적용. 통째로1360×212에늘리는방식 금지.
- 카드/선택 표식은432×440에맞출 때 중앙표식·상하코너가찌그러지지 않도록 border 또는분리sprite계획 필요. 상세의중앙장식도 단순9slice확대시늘어날수있어 고정장식별도처리 검토.
- 본문/스킬명/가격/아이콘은 그림에굽지않고 기존실제데이터 UI를 유지.

## 상태

- 이미지 후보 제작·파일 확인 완료. 승인 전 원본은 Art_Source에 보존, Assets 임포트/Unity 연결은 미진행.
- 후속: 후보별 실제표시크기 정렬/완성에셋 QA→Codex 이미지 임포트→Claude 최소연결코드. 게임전체 UI 일괄교체 금지.
- 새콘텐츠수/기능판정 변동이없어 간트완료율 변경없음. 기존미커밋코드/아이콘 보존. 빌드/테스트/Unity/Git반영 미실행.
