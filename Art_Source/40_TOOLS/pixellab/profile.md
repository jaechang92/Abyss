# PixelLab — 도구 프로필

> 채택 2026-09-06. **이 폴더는 버리는 층이다** — 도구가 바뀌면 여기만 새로 쓴다.
> 파라미터 실물은 `params.txt`. 이 문서는 **도구를 바꿀 때마다 다시 알아내야 했던 것들**을 적어 둔 곳이다.

---

## 1. 요약

| 항목 | PixelLab |
|---|---|
| 문구 문법 | **문장형.** 태그 나열이 아니다 |
| 문구 길이 한계 | 🔴 **대략 20~35 단어.** 길면 서로 희석되어 아무것도 안 걸린다 |
| 가중치 표기 | 없음 |
| **스타일 고정** | ✅ `style_image` + `style_strength`(0~100) |
| **팔레트 강제** | ✅ `color_image` — **부탁이 아니라 명령** |
| 부정 프롬프트 | ⚠️ `bitforge`만 유효. **`pixflux`에서는 deprecated** |
| 알파 | ✅ `no_background` 로 직접 낸다. 크로마키 불필요 |
| 면적 제한 | 무료 200x200 / tier1 320x320 / tier2+ 400x400 |
| 타일셋 | ✅ **웹 도구 Create Tileset** — Wang 타일셋을 dual-grid 15 / 3x3 으로 export |

### 앞 두 도구와의 결정적 차이

| | image_gen (gen1) | NovelAI V5 (gen2) | **PixelLab** |
|---|---|---|---|
| 스타일 고정 | 참조 이미지 첨부(수동) | ❌ **없음** | ✅ `style_image` |
| 팔레트 강제 | ❌ | ❌ | ✅ `color_image` |
| 알파 | 크로마키 추출 필요 | 직접 | 직접 |
| 타일 심리스 | ❌ | ❌ | ✅ Wang |

> 🔑 gen2 가 멈춘 이유가 이 표에 있다 — V5 에는 Vibe Transfer 도 Precise Reference 도 없어서
> *"정체성을 붙드는 것은 이 텍스트뿐"*이었다. **그 제약이 사라졌다.**
> 반대로 문구를 길게 쌓는 gen2 방식은 **여기서 역효과**다.

## 2. 두 모델

| | `pixflux` | `bitforge` |
|---|---|---|
| 용도 | **앵커 한 장** | 나머지 전부 |
| `style_image` | ✗ | ✅ 필수 |
| `negative_description` | 🔴 **deprecated — 안 먹는다** | ✅ 유효 |

> 💡 **왜 pixflux 로 시작하나** — `bitforge`는 `style_image`가 있어야 값을 한다.
> 첫 장은 참조할 것이 없으므로 `pixflux`다. 그 뒤로는 전부 `bitforge`다.
>
> 🔴 **앵커에서 인물·광원·이끼가 나오면 부정 프롬프트를 손보지 말고 다시 뽑는다.**
> 그 칸이 안 먹는다. 막는 것은 프롬프트가 아니라 **판정**이다 (`10_BIBLE/03-light.md §5`).

## 3. 순서 — 어기면 전부 다시 뽑는다

```
① 팔레트를 굽는다        50_BUILD/make_palettes.py  →  palettes/<scene>.png
② 조립한다               50_BUILD/build.py          →  assembled/
③ 앵커를 여러 장 뽑는다   pixflux + color_image      (bg_mid)
④ 사람이 한 장 고른다     →  anchors/<scene>.png
⑤ 나머지를 뽑는다         bitforge + style_image + color_image
⑥ 타일셋만 웹 도구로     Create Tileset
⑦ 한 씬을 Unity 재생까지 관통한다
⑧ 나머지 씬 반복
```

🔴 **①이 먼저인 이유** — `color_image`가 이 파이프라인에서 유일하게 **강제력이 있는** 장치다.
앵커를 뽑는 시점에 팔레트가 이미 있어야 한다.

🔴 **⑦을 건너뛰지 않는다.** 8씬 130장을 뽑은 뒤 임포트·슬라이스·패럴랙스 문제를 발견하면 전부 다시 한다.
gen2·gen3 가 둘 다 이 줄을 적어 두고도 지키지 못했다.

---

## 4. 세션 규약 🔴

**한 씬의 레이어들은 반드시 한 세션 안에서 끝낸다.**
패럴랙스는 여러 장이 겹쳐 보이는 구조라 색온도 차이가 그대로 층으로 드러난다.
날짜를 넘겨 이어 뽑으면 같은 설정이어도 갈린다 — gen2·gen3 가 둘 다 실측으로 적어 둔 것이다.

한 씬 안에서 `seed`를 고정한다. **예외는 프롭 하나** — 고정하면 다섯 개가 전부 닮은 물건이 된다.

---

## 5. Unity 임포트

| 대상 | 설정 |
|---|---|
| 배경 레이어 | Sprite(Single). 패럴랙스 계수는 먼 것이 덜 움직인다 |
| 타일셋 | Sprite(Multiple) → 격자 슬라이스 → Tile Palette |
| 발판·프롭 | Sprite(Single), 피벗 **Bottom** |

전부 **Filter Mode: Point (no filter)** · **Compression: None**.
픽셀 아트에 Bilinear 가 걸리면 확대할 때 뭉개진다.
