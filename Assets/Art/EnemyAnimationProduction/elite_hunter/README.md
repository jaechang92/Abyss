정체: 남겨진 얼굴 하나를 붙이고 몸의 나머지를 흉내 내다 만 것. 일반 적과 달리 땅에 선 세로 형체지만 어깨·팔 길이·가슴/허리가 어긋난다. 무기 없음, 손으로 붙잡으려 함.

## 시안 검토
- 밝은 얼굴판에 눈/코/곧은 입 선이 읽히며, 무표정 유지. 후드·갑옷·무기 없음.
- 좌우 어깨 높이와 팔 길이 차이, 좁은 허리, 팔다리 사이 빈 공간이 읽힌다.
- 차분한 재색 몸과 얼굴판 대비로 앞선 일반 적4종과 구분.
- 기획의 '얼굴판이 살짝 삐뚤게 붙음'은 약하며 머리가 크게 기울진 않는다. 몸도 목표의 짧고 덜 된 다리보다 긴 다리로 표현됐다. 사용자 판정 및 게임 축소 확인 필요.
- 색 수·밀도·폭높이비/80~88px 실측 완료로 표시하지 않는다. 녹색 배경 생성 원본은 투명 런타임 스프라이트가 아니다.
